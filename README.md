# V5 Local Scripts

English | [简体中文](README_zh.md)

An offline version of V5 with all networking features removed, adding and refining several others. Designed to run with [V5Loader-Offline](https://github.com/exhaust-pipe/V5Loader-Offline). No separate build is required, but installation and updates must be performed manually.

For installation instructions, please go to [V5Loader-Offline](https://github.com/exhaust-pipe/V5Loader-Offline)
